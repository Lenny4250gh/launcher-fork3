# Brazilian Portuguese (`pt`, shown as "Português (Brasil)")

Portuguese as written in Brazil. The player is addressed as **você**, in the imperative of "você" ("Escolha",
"Inicie"; not "Escolhe"). Real accents, ç and ã. The console language number is 17 (pt-BR). A system locale
`pt-PT` also gets this language.

## Format

| | |
|---|---|
| Decimal / thousands | `8,39 GB`, `65.340` |
| Date | `27 de out. de 2026, 14:32` (24-hour clock); months `jan. fev. mar. abr. mai. jun. jul. ago. set. out. nov. dez.` |
| Today / yesterday | Hoje / Ontem |
| Percent | `50%` (no space) |
| Plurals | **0 and 1 are singular** (CLDR): "1 jogo", "2 jogos"; where English says "No games" write "Nenhum jogo" |
