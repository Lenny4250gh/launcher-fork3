# Spanish (`es`)

Neutral Spanish that reads the same in Spain and Latin America. The player is addressed as **tú**, in the
imperative ("Elige", "Inicia"). Real accents and ñ; ¿ opens a question (no exclamations at all). The console
language number is 3 (Spain); a Latin American system locale (`es-MX`, `es-419`, `es-AR`, ...) sends 20.

## Format

| | |
|---|---|
| Decimal / thousands | `8,39 GB`, `65.340` |
| Date | `27 oct 2026, 14:32` (24-hour clock); months `ene feb mar abr may jun jul ago sept oct nov dic` |
| Today / yesterday | Hoy / Ayer |
| Percent | `50 %` with a no-break space where the program formats it |
| Plurals | singular for exactly 1, plural otherwise: "1 juego", "0 juegos", "3 juegos" |
| Quotes | « » around names, or none; never English "..." |
