# French (`fr`)

Standard French. The player is addressed as **tu** (informal, friendly), in the imperative ("Choisis", "Lance").
Real accents, ç and œ. The console language number is 2.

## Typography

- A **no-break space (U+00A0)** goes before `:` `;` `!` `?` `%` and inside « » (`« Jouer »`). Write it as `\u{a0}`
  in a Rust string.
- Apostrophe ’ (U+2019), as in "l’ami", "d’abord".
- Sentence case. No capital for months or language names inside a sentence.

## Format

| | |
|---|---|
| Decimal / thousands | `8,39 Go`, `65 340` (no-break space) |
| Units | octets, Ko, Mo, Go, To |
| Date | `27 oct. 2026, 14:32` (24-hour clock); months `janv. févr. mars avr. mai juin juil. août sept. oct. nov. déc.` |
| Today / yesterday | Aujourd’hui / Hier |
| Percent | `50 %` with a no-break space |
| Plurals | **0 and 1 are singular**: "0 jeu", "1 jeu", "2 jeux" |
