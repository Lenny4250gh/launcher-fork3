## AnyPlay Launcher 0.3.2

Fixes from your feedback on 0.3.1, and the launcher now works with Linux package managers.

### Fixes

- **Captures:** on an empty Captures page, the pad reaches the button again and the page scrolls to it.
- **Add a Friend:** screen readers now announce the result once: request sent, already friends, or why it could not be sent.
- **Profiles:** activity on a profile no longer shows reaction counts, so it looks the same as the Activity page.
- **Share screen on Linux:** if downloading the video codec failed, the launcher tries again the next time it starts or when you open Settings.

### Linux

- **Installed by a package manager:** a launcher installed as a Flatpak (and soon from the AUR) leaves its updates to the package manager. About shows when a new version is out and which package manager installs it, and the launcher never replaces its own files.

### Downloads

- Windows: `AnyPlay-Launcher-0.3.2-Setup.exe` (installer, no administrator rights needed) or `AnyPlay-Launcher-0.3.2-x64.exe` (one file).
- Linux: `AnyPlay-Launcher-0.3.2-x86_64.AppImage`, `AnyPlay-Launcher-0.3.2-linux-x86_64.tar.gz` or `AnyPlay-Launcher-0.3.2-x86_64.flatpak`.
- macOS (Apple silicon, macOS 11 or newer): `AnyPlay-Launcher-0.3.2-macos-arm64.zip`. If macOS says the developer cannot be verified, open **System Settings > Privacy & Security** and choose **Open Anyway**.
- The launcher you have offers this update by itself, on Windows, Linux and the Mac. It is signed like every update since 0.2.0.
